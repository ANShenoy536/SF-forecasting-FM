The example code `Los_PaperEg.zip` contains raw line-of-sight magnetograms downloaded from SHARP archives. This data can be pre-processed and used for running the training code under the 5 fold CV set up.
For training on the entire data and different FMs, please download the data as directed in `DataDownload` and proceed with `FieldMagGenerator.py` script and subsequent pre-processing codes.
